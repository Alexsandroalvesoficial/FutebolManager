# Futebol Manager ⚽

Jogo de gestão de futebol em português, feito para Android com interface adaptada a celulares.

## Recursos da versão inicial
- Elenco com posições e overall
- Simulação de partidas
- Campeonato e tabela
- Mercado de transferências
- Gestão básica do clube
- Salvamento local do progresso no dispositivo

## Gerar APK
O GitHub Actions compila automaticamente o aplicativo ao enviar alterações para a branch principal. Abra a aba **Actions**, selecione **Build Android APK** e baixe o artefato **FutebolManager-APK** quando a compilação terminar.

O APK de depuração é para testes e pode pedir confirmação do Android antes da instalação.
